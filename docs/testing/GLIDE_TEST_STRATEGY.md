## Hardware matrix and proof gates
At least two actual GMS Android devices are mandatory for M3. Record manufacturer/model, RAM class, OS/API/security patch, GMS version, app SHA/build type, radio/network topology and available storage. IDE device catalogs and emulators are not physical evidence.

Before release: low-end2–4GB RAM, midrange, flagship; at least3 manufacturers; API26/29 legacy storage,31/32 permission boundary,33/34 notification/FGS,35/36/37 target behavior represented by physical pair coverage where available. Emulators fill UI/API breadth, never replace radio/OEM evidence. If hardware is missing, document the exact uncovered matrix and block affected compatibility claims; do not mark full physical gate COMPLETE.

Run sender/receiver roles reversed. At least10 consecutive standard mixed batches per selected supported pair without corruption, false success or unclean partials; record attempts including failures. Zero hash mismatches among successful results. For repeatable environments target>=95% discovery/connect success within30s over20 attempts; investigate failures instead of excluding them. These are acceptance targets, not observed results.

## Chaos matrix
Inject at Negotiating, AwaitingConsent, Preparing, Streaming, Verifying and Committing:
- Wi-Fi/Bluetooth disabled, AP change, range loss, one endpoint killed.
- Screen lock both sides, recents swipe, task-manager stop, battery saver, Doze, thermal load.
- Source removed/revoked/unknown length/provider error, receiver disk filled midwrite.
- Cancel racing EOF/hash/success; drop final receipt; duplicate delayed callbacks.
- Malformed metadata, oversized stream, malicious name,1000 items, zero bytes, duplicate export names.
- Kill before/after journal write, fsync, rename and Room transaction; repeat recovery twice.

Expected results: never expose unverified file; verified files survive later failure; terminal states don't reopen; receiver consent never inferred; sender receipt ambiguity explicit; no automatic offset resume.

## Test data, reports and regression
Use generated non-sensitive test bytes, no personal photos. Hash source and received files independently; preserve fixture generation description and seed. Evidence includes command/exit result, artifact SHA, device table, steps, expected/actual, timing distribution, logs redacted and relevant screenshots. Store reports under docs/testing/evidence/ when executed; no fake empty “pass” files now.

CI runs deterministic unit/lint/build on each PR and emulator smoke on protected integration/nightly where resources permit. Physical gates are manual/test-lab artifacts attached before milestone closure. Flaky tests get owner and tracked diagnosis; quarantined release-critical tests block release. No arbitrary coverage percentage replaces transition/requirements coverage. [DoD](../DEFINITION_OF_DONE.md) governs completion.
