   - Coordinates the complete remote session state machine: `Created` -> `AwaitingUserConsent` -> `Signaling` -> `GatheringCandidates` -> `NegotiatingPath` -> `Transferring` -> `Completed` / `Failed`.
   - **Metered Cellular Protection (Threat R05):** Evaluates `MeteredTransferPolicy` before signaling; prompts user with item name, formatted byte size, and cellular fee warnings (`[Cancel Transfer]` vs `[Proceed on Cellular]`).

   - **Stale Invitation Rejection (Threat R06):** Rejects expired invitations (`IsExpired()`).
