### 1.2 Bounded Thumbnail Decoding (`:data`)
- Created [`BoundedThumbnailDecoder.kt`](../../../data/src/main/kotlin/dev/glide/data/media/BoundedThumbnailDecoder.kt) providing memory-safe, downsampled bitmap decoding from untrusted files:
  - Strict dimensions ceiling ($\le 512\text{px}$) and memory ceiling ($\le 4\text{ MiB}$ per thumbnail).
  - Pre-flight dimension checks using `inJustDecodeBounds = true`.
  - Optimal power-of-2 `inSampleSize` computation to bound both axes.
  - Defense-in-depth against decompression bombs ($> 16,384\text{px}$ or raw uncompressed $> 64\text{ megapixels}$) mitigating Threat T14.
  - Created [`BoundedThumbnailDecoderTest.kt`](../../../data/src/test/kotlin/dev/glide/data/media/BoundedThumbnailDecoderTest.kt) (7/7 PASS).
