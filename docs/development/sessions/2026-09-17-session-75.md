2. **Phase W1 Embedded Web Assets (`windows/Glide.Transport/Web/Assets/`):**
   - Self-contained Single-Page Application (HTML5 / CSS3 / ES2020) compiled directly into `Glide.Transport.dll` via `<EmbeddedResource Include="Web\Assets\**\*" />`.
   - `index.html`: Responsive layout, inline SVG brand icons, download cards, and drag-and-drop upload zone.
   - `style.css`: Fluent/Material dark theme tokens, mobile layout breakpoints, and progress bars.
   - `app.js`: Vanilla JavaScript fetching manifest, triggering chunked downloads, and handling drag-and-drop multipart uploads with live progress tracking.
   - **Zero External CDN Calls:** Completely offline and air-gapped; no external scripts, fonts, stylesheets, or remote telemetry.

3. **`GlideWebGateway` HTTP/1.1 Server (`windows/Glide.Transport/Web/GlideWebGateway.cs`):**
   - Zero-dependency embedded HTTP server leveraging .NET `System.Net.HttpListener`.
   - Binds strictly to the local Wi-Fi IP and dynamic port `0` (ephemeral).
   - Generates 256-bit cryptographically secure bearer token (`RandomNumberGenerator`) with 120-second monotonic TTL.
   - One-use token onboarding: exchanges `?token=<hex>` for an `HttpOnly; SameSite=Strict` cookie (`glide_web_session`).
   - Strict security headers on every response: `Content-Security-Policy`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Cache-Control: no-store`.
   - High-throughput binary streaming downloads with `Content-Disposition: attachment; filename="..."`.
   - Streaming uploads directly into `QuarantineStagingStore` with on-the-fly SHA-256 verification and atomic commit to `Downloads`.

4. **CLI & Desktop UI Integration:**
   - **CLI (`windows/Glide.App/Program.cs`):** Added `glide web [--port <port>] <file-paths...>` command for instant web sharing from PowerShell/Command Prompt.
   - **Desktop GUI (`windows/Glide.Windows.UI`):**

     - Added Web Share modal overlay with onboarding URL display, `📋 Copy Web Share Link` clipboard button, and `⏹ Stop Web Share` server shutdown.
