- **Milestone:** M6 — Premium UI (Task 4 of 9 in M6, overall 38 of 68).
- **Priority:** P2.
- **Scope & Acceptance Criteria:**
  - Strict separation of Connection Verification (SAS PIN digit comparison) and Transfer Offer Consent surfaces to eliminate any accidental combined acceptance.
  - Verification surface polish (`PairingVerificationCard.kt`):
    - Untrusted peer display name with device type icon, "Untrusted until verified" caption, and same-name disambiguation chip (`#xxxx`).
    - Local device context label ("This device: Pixel 10 Pro").
    - High-contrast, individual monospace digit boxes (4 or 6 digits) with clear separation.
    - TalkBack comma-separated digits semantics for clear digit-by-digit screen reader pronunciation.
    - 60s countdown timer with breathing hourglass badge and warning state when $\le 10$s.
    - Vertically stacked button hierarchy: Primary "Numbers match" ($\ge 56\text{dp}$, filled) above secondary "Don't match" ($\ge 52\text{dp}$, outlined), immune to clipping at 200% font scale.
    - Confirmed state: "Waiting for {peerName} to confirm…" with circular progress indicator and cancel button.
  - Offer consent surface polish (`OfferConsentCard.kt`):
    - Receiver header with peer name, device glyph, item count, and total formatted size.
    - Scrollable item list showing file type badges (IMG, VID, PDF, PPTX, ZIP, TXT, FILE), 2-line safe filenames, and byte sizes.
    - Mandatory private storage guarantee banner: *"Saved in Glide; export to keep outside app"*.
    - Device storage space validation: Compares available disk space against batch requirement. If insufficient, displays error alert banner and disables "Accept transfer".
    - 60s countdown timer badge.
    - Action buttons: Primary "Accept transfer" / "Accept {n} files" ($\ge 56\text{dp}$) and secondary "Decline" ($\ge 52\text{dp}$).
    - Sender waiting view with batch summary, progress indicator, and cancel action.
  - Predictive / system `BackHandler` in `TransferScreen.kt` cleanly cancels pairing or declines offers without leaving orphan staging files.
  - Automated unit and acceptance tests covering both surfaces.
  - Live physical verification with 7 screenshots on `Pixel_10` emulator (Android 17 / API 37).
