## 1. Summary of Changes

Delivered **Milestone M17 (Phase W4)**, implementing secure, single-pass quarantine file uploads with browser preflight proposals, disk space threshold enforcement, incremental SHA-256 integrity verification, instant quarantine purge on checksum mismatch, and strict cross-platform filesystem sanitization:

1. **Windows .NET Quarantine Uploader & Staging Engine (`windows/Glide.Transport` & `windows/Glide.Core`):**
   - **Upload Proposal Flow (`POST /api/v1/upload/proposal`):**
     - Parses JSON preflight proposal `{ fileName, fileSize, mimeType?, sha256? }`.
     - Validates available staging drive storage via `_quarantineStore.GetAvailableFreeSpaceBytes()`.
     - Returns `507 Insufficient Storage` if free space < `fileSize + 50MB` safety buffer.
     - Sanitizes filename via `WindowsPathSanitizer.SanitizeWebFilename`.
     - Returns `200 OK` with JSON `{ status: "accepted", uploadId: "<guid>", fileName: "...", maxChunkSize: 65536 }`.
   - **Streaming Upload with Incremental SHA-256 & Purge (`POST /api/v1/upload`):**
     - Preflight storage check on declared item size (`507 Insufficient Storage`).
     - Streams directly into quarantine staging (`%LocalAppData%\Glide\staging\<sessionId>\<itemId>.quarantine`) with incremental SHA-256 calculation ($O(1)$ memory).
     - Compares optional `X-Declared-Sha256` header against computed hash.
     - On checksum mismatch: instantly purges the quarantine file via `_quarantineStore.PurgeQuarantine(sessionId, itemId)` and returns `422 Unprocessable Entity` with `{ status: "error", error: "checksum_mismatch", declared: "...", actual: "..." }`.
     - On verification: commits file atomically to user's `Downloads/` directory using collision-safe naming.
   - **`WindowsPathSanitizer.cs` (`Glide.Core.Storage`):**
     - Added `SanitizeWebFilename(rawName, fallback)` adhering to Section 5.3: Unicode NFC normalization, drive prefix stripping (`C:\`), traversal `..` stripping, leading slash stripping, illegal Windows character replacement (`< > : " / \ | ? *`), reserved DOS device name escaping (`CON`, `PRN`, `AUX`, `NUL`, `COM1-9`, `LPT1-9`), and 255-character truncation.
   - **`QuarantineStagingStore.cs` (`Glide.Core.Storage`):**
     - Exposed `StagingRoot`, `DestinationRoot`, and `GetAvailableFreeSpaceBytes()`, supporting deterministic mock testing via `freeSpaceProvider`.
   - **Unit & Integration Tests (`WebGatewayIntegrationTests.cs` & `WindowsPathSanitizerTests.cs`):**
     - Added 5 integration tests covering proposal acceptance, 507 Insufficient Storage, SHA-256 verified commitment, 422 mismatch rejection + quarantine purge, and path traversal / reserved DOS escaping.
     - Added 2 theories in `WindowsPathSanitizerTests.cs`.
     - **141 / 141 .NET tests passing (100%)**.
