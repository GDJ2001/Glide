## 1. Summary of Changes

Delivered the complete **Glide.Windows** companion desktop client solution in `windows/Glide.slnx` (.NET 10 / C# 13 / WPF), providing seamless, private, high-throughput offline file transfers between Android and Windows devices over local Wi-Fi and Ethernet subnets:

1. **`windows/Glide.Core` (.NET 10 Class Library):**
   - **Protocol V1 Engine:** Exact JSON envelope schema, sequencers, depth/byte bound validators (`ProtocolCodec.cs`), validated against 20+ golden protocol fixtures.
   - **LAN Profile 1 Framing:** Typed records (`BOOTSTRAP`, `BOOTSTRAP_RESULT`, `CONTROL`, `DATA`, `STREAM_END`) in `LanRecord.cs`, `LanRecordCodec.cs` with 5-byte header (`kind: byte` + `payloadLength: UInt32` big-endian) and 64 KiB ceiling.
   - **RFC 4122 UUID Serialization:** `LanUuidCodec.cs` enforcing standard big-endian network byte order for bulk stream identifiers.
   - **QR Pairing Invitation Codec:** `InvitationCodec.cs` for `glide://pair/v1#<unpadded-base64url>` encoding/decoding, URI length $\le 2768$, JSON $\le 2048$, with automatic token redaction.
   - **Security & Filesystem Invariants:** Canonical `SasCalculator.cs` (`ExtractDecimal6`), `WindowsPathSanitizer.cs` (blocking traversal, drive letters, UNC, and DOS devices `CON`, `PRN`, `AUX`, `NUL`), and `QuarantineStagingStore.cs` (sandboxed staging with atomic rename).

2. **`windows/Glide.Transport` (.NET 10 Class Library):**
   - **Zero-Dependency mDNS Discovery:** `MdnsDiscoveryService.cs` implementing RFC 6762 / RFC 6763 multicast UDP responder and browser for `_glide._tcp.local.` on `224.0.0.251:5353`.
   - **Framing Channels:** `LengthPrefixedFrameChannel.cs` (control framing) and `LanRecordChannel.cs` (thread-safe Profile 1 serialized records with `SemaphoreSlim` write lock).
   - **TLS 1.3 with Out-of-Band SPKI Pinning:** `TlsSocketClient.cs` and `TlsSocketListener.cs` negotiating ALPN `glide-lan/1` / `glide-v1` and enforcing exact DER SubjectPublicKeyInfo SHA-256 fingerprint matching before any application bytes leave the client.

3. **`windows/Glide.Windows.UI` (.NET 10 WPF Modern Desktop GUI):**
   - Modern dark-themed user interface (`MainWindow.xaml`, `App.xaml`) with clean Fluent typography and styling.
   - Reactive MVVM architecture (`MainViewModel.cs`, `DiscoveredPeerViewModel.cs`, `RelayCommand.cs`).
   - Live mDNS peer cards with device badges (📱 / 💻) and 1-click peer selection.
   - "Pair via Link / QR" modal dialog for entering `glide://pair/v1#...` links.
   - Receive view with ephemeral QR invitation generation, 1-click clipboard copy, real-time speed tracking, active file name indicator, and automatic commit to `Downloads`.

4. **`windows/Glide.App` (.NET 10 High-Throughput CLI):**
   - Command-line tool supporting `send`, `receive`, `pair`, `list`, and `version`.
   - Supports `--pair <uri>` out-of-band SPKI pinning and streaming via `LanRecordChannel`.

5. **`windows/Glide.Tests` (.NET 10 Test Suite):**
   - 107 / 107 tests passing (100% success rate).
   - Conformance against 20+ Protocol V1 golden JSON envelopes.
   - 100% byte-for-byte matching across all 7 LAN Profile 1 golden binary fixtures.
   - End-to-end loopback TLS 1.3 batch transfer tests (`LanProfile1TransferIntegrationTests.cs`) verifying full transfer, SPKI mismatch abort, zero-byte stream end handling, corrupted chunk quarantine purge, and invalid token rejection.
