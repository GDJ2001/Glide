## 1. Summary of Changes

Delivered **Milestone M20**, fulfilling Step 5 of the Glide Cross-Platform Path ([`CROSS_PLATFORM_PATH.md`](../../future/CROSS_PLATFORM_PATH.md)), establishing the Linux platform architecture, FreeDesktop.org desktop integration, XDG directory compliance, headless terminal pairing, and systemd service management:

1. **Architectural Decision Record Authored & Accepted ([`docs/adr/ADR-0021-linux-platform-architecture.md`](../../adr/ADR-0021-linux-platform-architecture.md)):**
   - Evaluated native rewrite in C/Rust (rejected: code duplication and maintenance risk), Python/Electron wrapper (rejected: memory/binary bloat), and shared cross-platform .NET 10 engine (adopted).
   - Reuses `Glide.Core`, `Glide.Transport`, and `Glide.App` (`net10.0`) directly, guaranteeing 100% protocol and golden fixture conformance.
   - Enforced 100% offline, zero-cloud operations over local LAN using TLS 1.3 mutual authentication, SPKI pinning, and 6-digit numeric SAS verification.
   - Mandated FreeDesktop.org standards: XDG Base Directory specification (`$XDG_DATA_HOME`, `$XDG_CONFIG_HOME`, `$XDG_DOWNLOAD_DIR`), desktop entry (`glide.desktop`), and systemd user service (`glide.service`).
   - Defined terminal ANSI/UTF-8 half-block QR code rendering for headless server and SSH sessions.
   - Added ADR-0021 to the authoritative index in [`docs/adr/README.md`](../../adr/README.md).

2. **Linux Platform Technical Specification ([`docs/future/LINUX_PLATFORM_SPECIFICATION.md`](../../future/LINUX_PLATFORM_SPECIFICATION.md)):**
   - Authoritative 10-section specification covering: Executive Summary, System Architecture & CLI/Daemon Mapping, FreeDesktop & XDG compliance, Terminal QR rendering, mDNS discovery & Avahi coexistence, POSIX/Linux filesystem sanitization, desktop environment integration, systemd user service management, packaging & deployment targets (single-file ELF binary for x64/arm64, container images), and conformance testing.

3. **Cross-Platform Code Hardening:**
   - **`QuarantineStagingStore.cs` ([`windows/Glide.Core/Storage/QuarantineStagingStore.cs`](../../../windows/Glide.Core/Storage/QuarantineStagingStore.cs)):**
     - Added `GetDefaultStagingRoot()` checking `$XDG_DATA_HOME/glide/staging` on Linux with standard `SpecialFolder.LocalApplicationData` fallback.
     - Hardened `GetAvailableFreeSpaceBytes()` to dynamically resolve drive root (`Path.GetPathRoot(...) ?? (OperatingSystem.IsWindows() ? "C:\\" : "/")`) preventing `DriveInfo` exceptions on Linux filesystems.
   - **`Program.cs` ([`windows/Glide.App/Program.cs`](../../../windows/Glide.App/Program.cs)):**
     - Replaced hardcoded `platform: "windows"` in `LanInvitation` with dynamic `GetCurrentPlatform()` (`linux`, `windows`, `macos`).
     - Updated banner to dynamically display `Glide.Linux`, `Glide.macOS`, or `Glide.Windows`.
     - Dynamically bound CLI console messages and committed file destinations to `stagingStore.StagingRoot` and `stagingStore.DestinationRoot`.

4. **Automated Specification Auditor ([`tools/verify-linux-platform-spec.ps1`](../../../tools/verify-linux-platform-spec.ps1)):**
