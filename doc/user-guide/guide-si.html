1. ආරම්භය සහ පළමු file යැවීම

Glide 1.0.0 යනු අන්තර්ජාලය, cloud storage හෝ ගිණුම් කිසිවක් නොමැතිව එකම Wi-Fi / Ethernet ජාලය තුළ පවතින Windows, Ubuntu/Linux සහ Android උපාංග අතර ආරක්ෂිතව files හුවමාරු කරන මෘදුකාංගයකි. UI බොත්තම් සහ tab නම් යෙදුමේ පෙනෙන English ආකාරයෙන්ම දක්වා ඇත.

ඉක්මන් ආරම්භය A: Android → Windows (පළමු වරට file එකක් යැවීම)

  1. එකම ජාලයට සම්බන්ධ වන්න: Android phone එක සහ Windows PC එක එකම Wi-Fi / LAN router එකට සම්බන්ධ කරන්න.
  2. Windows හි Start receiving ඔබන්න: Windows Glide විවෘත කර වම් මෙනුවේ Receive → Start receiving click කරන්න.
  3. Android හි files තෝරන්න: Phone එකේ Glide විවෘත කර Send files → Choose photos & videos හෝ Choose files & documents → Proceed to send tap කරන්න.
  4. PC QR code එක scan කරන්න: Android හි Scan QR code or paste invite tap කර Windows තිරයේ පෙනෙන QR එක scan කර Connect ඔබන්න.
  5. Windows හි Accept transfer ඔබන්න: PC තිරයේ එන Incoming transfer කවුළුවේ යවන්නා සහ file විස්තරය බලා Accept transfer click කරන්න.
  6. Received files මඟින් බලන්න: අවසානයේ ඉහළ දකුණේ ඇති Received files click කර save වූ file එක විවෘත කරන්න.

ඉක්මන් ආරම්භය B: Windows → Android (QR හෝ Paired device මඟින් යැවීම)

  1. Android හි Receive files විවෘත කරන්න: Phone එකේ Glide open කර Receive files tap කරන්න.
  2. Windows හි files එකතු කරන්න: Windows Glide හි Send පිටුවේ Add files හෝ Add folder මඟින් files තෝරන්න.
  3. QR හෝ Paired device තෝරන්න: පළමු වරට යවන්නේ නම් Quick share with QR ඔබන්න (පෙර pair කළ phone එකක් නම් Paired device තෝරන්න).
  4. Phone එකෙන් scan කරන්න (QR ක්‍රමයේදී): Android තිරයේ Scan PC QR code tap කර Windows හි QR එක scan කරන්න.
  5. වැදගත් පියවර — Windows හි Send files ඔබන්න: Phone එක scan කළ පසු Windows හි Confirm receiving device පණිවිඩය එයි; එහි Send files අනිවාර්යයෙන්ම click කරන්න.
  6. Phone එකේ Accept file tap කරන්න: Android හි Accept file ඔබා අවසන් වූ පසු Verified සලකුණ සමඟ Download/Glide හි save වේ.

2. තිර හඳුනාගැනීම

Platforms තුනේම ප්‍රධාන කොටස් එකම ආකාරයට සකසා තිබුණද, බොත්තම් නම්වල කුඩා වෙනස්කම් ඇත:

  • Windows vs Linux Receive බොත්තම: Windows හි Start receiving / Stop receiving ලෙසත්, Ubuntu Linux හි Turn on receiving / Turn off receiving ලෙසත් පෙන්වයි.
  • Header හි Received files සහ Sharing is local: Windows සහ Linux දෙකෙහිම ඉහළ තීරුවේ ඇති Received files බොත්තමෙන් ලැබුණු ගොනු folder එක කෙලින්ම විවෘත වේ. Sidebar පහළ ඇති Sharing is local කාඩ්පත සෑම transfer එකක්ම අන්තර්ජාලයෙන් තොරව local ජාලයේ සිදුවන බව තහවුරු කරයි.
  • Android Home Paired devices ලැයිස්තුව: ඔබ පෙර pair කළ devices මෙහි Paired ලෙස හෝ අවසන් වරට සම්බන්ධ වූ වේලාව (Last seen ...) සමඟ දැක්වේ.

3. Devices pair කිරීම

වැදගත් වෙනස: Pair-only QR vs Transfer QR

Pair devices පිටුවේ ඇති QR code එක (Pair-only QR) භාවිතා කරන්නේ අනාගතයේදී ඉක්මනින් files යැවීම සඳහා devices දෙක අතර විශ්වාසය (trust) save කිරීමට පමණි — එයින් files යැවෙන්නේ නැත. එවෙලේම files යැවීමට නම් Send → Quick share with QR හෝ Receive පිටුවේ ඇති Transfer QR භාවිතා කරන්න.

A. Desktop පරිගණක දෙකක් (Windows ↔ Linux / PC ↔ PC) pair කිරීම

  1. පළමු පරිගණකයේ: වම් මෙනුවේ Pair devices විවෘත කර Show my QR and code tab එක තෝරන්න. එහි පෙන්වන ඉලක්කම් 6 කේතය (6-digit code) තබාගන්න (කල් ඉකුත් වූවොත් New code ඔබන්න).
  2. දෙවන පරිගණකයේ: Pair devices → Find devices වෙත ගොස් ලැයිස්තුවේ පෙනෙන අනෙක් PC එක click කරන්න.
  3. කේතය ඇතුළු කරන්න: පළමු පරිගණකයේ පෙන්වන ඉලක්කම් 6 type කර Pair click කරන්න.
  4. දෙපසම Approve කරන්න: ලැබෙන පණිවිඩයේ device නම නිවැරදි නම් Approve click කරන්න. එවිට Done සමඟ Paired devices ලැයිස්තුවට එක් වේ.

9. නිතර අසන ප්‍රශ්න, සීමාවන් සහ වචන මාලාව

1. මට අන්තර්ජාලය (Internet) හෝ ගිණුමක් (Account) අවශ්‍යද?

නැත. Glide 100% අන්තර්ජාලයෙන් තොරව (offline) ක්‍රියා කරයි. එකම Wi-Fi / LAN ජාලය හෝ Nearby Connections පමණක් ප්‍රමාණවත්ය; login වීම හෝ cloud storage භාවිතයක් නැත.

2. Glide නොමිලේ ලබා ගත හැකිද?

ඔව්. Glide 1.0.0 සම්පූර්ණයෙන්ම නොමිලේ ලබා දෙන විවෘත කේත (open-source) මෘදුකාංගයකි.

3. මෙය ආරක්ෂිත සහ පෞද්ගලිකද?

ඔව්. LAN හරහා සෑම transfer එකක්ම TLS 1.3 සහ SPKI public-key pinning මඟින් encrypt වේ. ලැබෙන files ප්‍රථමයෙන් පෞද්ගලික staging ප්‍රදේශයක SHA-256 පරීක්ෂාවට ලක් කර නිවැරදි නම් පමණක් save කරයි.

4. සෑම transfer එකක්ම අනුමත කිරීමට සිදුවන්නේ ඇයි (QR scan කළ පසුවත්)?

වැරදීමකින් හෝ ඔබේ කැමැත්තෙන් තොරව කිසිවෙකුට files එවීම වැළැක්වීමටය. එම නිසා ලබන්නා Accept file / Accept transfer එබිය යුතු අතර, Quick Share QR scan කළ පසු යවන්නාද Windows හි Send files (Linux හි Confirm Recipient) මඟින් තහවුරු කළ යුතුය.

5. <code>Verified</code> යන්නෙන් අදහස් කරන්නේ කුමක්ද?

ඔබේ device එකට ලැබුණු file එකේ එක් byte එකක්වත් වෙනස් නොවී මුල් file එකට 100% සමාන බව SHA-256 checksum මඟින් තහවුරු කළ බවයි.

6. QR වර්ග දෙකක් (Pair-only QR සහ Transfer QR) තිබෙන්නේ ඇයි?

Pair devices තුළ ඇති Pair-only QR එක දිගුකාලීනව devices හඳුනාගැනීම save කිරීමට පමණි. එවෙලේම files හුවමාරු කිරීමට Quick share with QR හෝ Receive හි ඇති Transfer QR භාවිතා කරයි.
