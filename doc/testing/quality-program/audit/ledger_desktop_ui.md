# Complete Review Ledger — Desktop UI, UI Tests, and UI Benchmarks

**Scope**:
- Windows WPF UI: `desktop/windows/Glide.Windows.UI/` (all tracked first-party files)
- Linux Avalonia UI: `desktop/linux/Glide.Linux.UI/` (all tracked first-party files)
- UI Tests: `desktop/tests/Glide.Windows.UI.Tests/` and UI/presentation/selection tests in `desktop/tests/Glide.Tests/`
- UI Benchmarks: `android/benchmark/src/main/kotlin/dev/glide/benchmark/` (specifically `TransferDisplayBenchmark.kt`, `NavigationBenchmark.kt`, `StartupBenchmark.kt`, `BaselineProfileGenerator.kt`) and `android/app/src/benchmark/` (`DebugLaunchHarness.kt`), plus `tools/run-transport-benchmark.ps1`
- Shared Desktop Presentation/Selection/Rate services referenced directly by UI: `DesktopTransferPresentation.cs`, `DesktopTransferSelection.cs`, `DesktopTransferRateCalculator.cs`

**Ranking Legend**:
- **[1]** Security / data loss / incorrect completion
- **[2]** Connection / lifecycle reliability
- **[3]** Performance (UI dispatch, coalescing, rendering, main-thread blocking)
- **[4]** Usability / flow / accessibility / maintainability
