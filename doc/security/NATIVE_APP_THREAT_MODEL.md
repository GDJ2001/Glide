# Native Glide application threat model

Updated 2026-10-01. Scope: local-network file sharing between Android, Windows, Linux, iOS/iPadOS, and macOS. Browser file transfer is retired. The status column describes source implementation at recovery time, not a passed validation gate.

| Threat / boundary | Required control | Production source | Status | Phase 2 evidence required |
|---|---|---|---|---|
| Discovery impersonation | Treat mDNS and display names as availability only; bind the transfer to a fresh authenticated invitation and TLS certificate SPKI | `DesktopTransferEngine`, `DesktopInvitationManager`, `InvitationCodec`; Android `transport-lan`; Apple `InvitationCodec`/`GlideTlsParameters` | .NET present; Apple listener identity incomplete | Cross-platform wrong-pin, wrong-endpoint, replay fixtures and physical wrong-device attempt |
| Unauthorized file delivery | Ask the recipient to approve each offered batch, even from trusted peers | `DesktopTransferModels`, Windows/Linux view models; Android consent UI; Apple view models | .NET/Linux fail-closed path added; Apple engine remains disabled | Reject and trusted-peer interactive offer tests on all clients |
| Wrong recipient for sender-hosted QR | Confirm recipient identity before sending selected files | `DesktopTransferEngine.SendHostedAsync`, Windows/Linux recipient prompt | Linux prompt wired; physical check pending | QR role in both directions, cancel and wrong-name cases |
| Oversized or malformed records | Bound control frames to 16 KiB and bulk chunks to 64 KiB, reject unexpected controls and lengths | `LanRecordChannel`, `DesktopTransferEngine`; Android protocol codec; Apple `LanRecordChannel` | .NET/Android source present; Apple full session incomplete | Shared malformed and boundary fixtures in Kotlin/C#/Swift |
| Quarantine bypass or corrupt file | Private staging; independently hash actual bytes; compare declared length and ITEM_END digest; commit only after verification | .NET `QuarantineStagingStore`/`DesktopTransferEngine`; Android `QuarantineStagingStore`; Apple staging | Apple engine disabled because previous self-comparison was unsafe | Corrupt digest, truncation, symlink, collision, disk-full, restart cases |
| Persistent identity misuse | Verify peer proof and allow explicit enrollment/revocation; trust never implies offer approval | `DesktopPersistentTrustManager`, Linux/Windows trust UI; Android identity store | Linux trust manager wired; Apple persistence incomplete | Enrollment, impersonation, revocation, identity-loss tests |
| Concurrent process or batch conflict | One active batch and one per-user listener owner; bound accepted connections and await shutdown | `DesktopTransferRuntime`, `DesktopListenerSupervisor`, `LinuxSingleInstance` | Single-batch and sequential listener source present; GUI/daemon ownership still open | Duplicate launch and concurrent GUI/daemon cases |
| Secret leakage | Keep tokens and keys out of logs/notifications and release artifacts; restrict desktop stores and Apple/Android key stores | `LanInvitation.ToString`, desktop trust stores, platform notifications | Review incomplete | Log/notification scan, store permissions, package inspection |
| Stale or substituted artifact | Build every package from one clean commit; record toolchain and fresh hash; sign outside untrusted PR jobs | `tools/package-*`, CI workflows | Open | Manifest hash/provenance, install/upgrade/uninstall on target OS |

Residual blockers: a Mac/Xcode host, Linux runtime hosts, physical devices for the platform matrix, and five usability participants. No historical documentation-only check closes these gates.
