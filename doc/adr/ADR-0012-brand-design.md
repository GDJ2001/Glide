# ADR-0012 — Brand and design system

- Status: Accepted (planning); validation pending implementation evidence.
- Date:2026-09-12.
- Authority: [specification](../design/BRAND_ASSET_CHECKLIST.md); [decision index](README.md).

## Context
Accepted raster work exists with incomplete native exports.

## Options considered
Regenerate; replace with stock icons; preserve with faithful derivatives.

## Decision
Preserve existing masters; branded default/dynamic opt-in, restrained depth and accessible adaptive tokens.

## Reasoning
Protects user decisions while making premium UI consistent.

## Consequences
Native launcher/themed/notification/splash work remains; raster geometry variations disclosed.

## Alternatives and migration/fallback
Human-reviewed faithful vector/layer derivation later; never silently redraw.

Use [change control](../development/CHANGE_CONTROL.md) for deviations. The linked specification supplies detailed requirements and official sources; this ADR records why, not another duplicate version table.
