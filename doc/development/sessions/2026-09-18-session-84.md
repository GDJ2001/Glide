## 1. Summary of Changes

Delivered **Milestone M23**, completing Phase R1 (Ephemeral Remote Invitation & Codec Engine) and Phase R2 (STUN Client & Server-Reflexive Candidate Discovery) of the Remote Internet Transfer architecture ([`REMOTE_INTERNET_TRANSFER_SPECIFICATION.md`](../../future/REMOTE_INTERNET_TRANSFER_SPECIFICATION.md)):

1. **Cross-Platform Remote Invitation Domain Model & Codec:**
   - Authored [`windows/Glide.Core/Remote/RemoteInvitation.cs`](../../../windows/Glide.Core/Remote/RemoteInvitation.cs) and [`transfer-core/src/main/kotlin/dev/glide/core/remote/RemoteInvitation.kt`](../../../transfer-core/src/main/kotlin/dev/glide/core/remote/RemoteInvitation.kt).
   - Encapsulates `rendezvousId` (canonical UUIDv4), `ephemeralPublicKeyHex` (64 hex characters for X25519 key exchange), `signalingEndpoint` (valid `wss://`/`ws://` URI), `relayBlindToken` (Base64url), `expiresAt` (Unix timestamp, <= 120s TTL), and `ttlSeconds`.
   - Authored [`windows/Glide.Core/Remote/RemoteInvitationCodec.cs`](../../../windows/Glide.Core/Remote/RemoteInvitationCodec.cs) and [`transfer-core/src/main/kotlin/dev/glide/core/remote/RemoteInvitationCodec.kt`](../../../transfer-core/src/main/kotlin/dev/glide/core/remote/RemoteInvitationCodec.kt).
   - Formats and strictly parses `glide://remote/v1#id=<UUID>&key=<HEX>&sig=<URL_ENCODED>&token=<TOKEN>&exp=<TIMESTAMP>`.
   - Enforces 2,048 character URI length ceiling, exact 5-parameter completeness, unknown parameter rejection, duplicate key rejection, and expiration enforcement.

2. **Zero-Dependency RFC 8489 STUN Client ([`windows/Glide.Transport/Remote/StunClient.cs`](../../../windows/Glide.Transport/Remote/StunClient.cs)):**
   - Pure C# implementation over UDP without third-party frameworks.
   - Builds 20-byte STUN Binding Request (`0x0001`) with Magic Cookie `0x2112A442` and 96-bit random Transaction ID.
   - Parses STUN Binding Success Response (`0x0101`), validates Magic Cookie and Transaction ID matching.
   - Extracts `XOR-MAPPED-ADDRESS` (`0x0020`) for IPv4 and IPv6, de-XORing port with `0x2112` and IP address with Magic Cookie / Transaction ID.
   - Fallback support for RFC 5389 `MAPPED-ADDRESS` (`0x0001`).
   - Implements asynchronous `QueryServerReflexiveAddressAsync` with configurable timeout and DNS resolution.
