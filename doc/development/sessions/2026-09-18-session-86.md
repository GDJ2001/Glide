## 1. Summary of Changes

Delivered **Milestone M25**, completing Phase R3 (Blind TURN Relay Fallback & Anti-Abuse Engine) and Phase R4 (Metered Data Invariant Protection) of the Remote Internet Transfer architecture ([`REMOTE_INTERNET_TRANSFER_SPECIFICATION.md`](../../future/REMOTE_INTERNET_TRANSFER_SPECIFICATION.md)):

1. **Zero-Dependency RFC 8656 TURN Relay Client ([`windows/Glide.Transport/Remote/TurnClient.cs`](../../../windows/Glide.Transport/Remote/TurnClient.cs)):**
   - Pure C# client over UDP implementing Traversal Using Relays around NAT (TURN).
   - Operates strictly under the **Blind Packet Forwarder** invariant: relay forwards opaque, end-to-end encrypted `LanRecord` frames without payload inspection or decryption capability.
   - Builds and parses:
     - Allocate Request (`0x0003`) / Allocate Success Response (`0x0103`) extracting `XOR-RELAYED-ADDRESS` (`0x0016`) and `LIFETIME` (`0x000D`).
     - CreatePermission Request (`0x0008`) / Success Response (`0x0108`) with `XOR-PEER-ADDRESS` (`0x0012`).
     - Send Indication (`0x0016`) and Data Indication (`0x0017`) with `DATA` (`0x0013`) payload attributes.
     - ChannelData message framing (`0x4000` through `0x7FFE`) for high-throughput, low-overhead relayed transfers.
   - Added `CreateRelayedCandidate` generating standard RFC 8445 `IceCandidate` instances with `CandidateType.Relayed`, priority computation (typePref = 0), and related base host endpoint mapping.
   - Added `ComputeFoundation` RFC 8445 foundation generator in [`windows/Glide.Core/Remote/IceCandidate.cs`](../../../windows/Glide.Core/Remote/IceCandidate.cs).

2. **Relay Quota Tracker & Anti-Abuse Engine ([`windows/Glide.Core/Remote/RelayQuotaTracker.cs`](../../../windows/Glide.Core/Remote/RelayQuotaTracker.cs)):**
   - Enforces the strict anti-abuse rules from Section 5.2 of the Remote Specification and ADR-0022:
     - **100 MB Hard Ceiling:** `MaxRelayBytesPerTransfer = 100 * 1024 * 1024` (104,857,600 bytes) per transfer on public/community relays. Throws `RelayQuotaExceededException` upon breach.
     - **Session Concurrency Cap:** Maximum 3 concurrent remote transfer sessions (`MaxConcurrentSessions = 3`). Throws `RelayConcurrencyLimitExceededException` upon exceeding.
     - **Sliding-Window Rate Limiting:** Maximum 10 connection attempts per sliding 60-second window (`MaxAttemptsPerMinute = 10`). Throws `RelayRateLimitExceededException` on excess attempts.
   - Thread-safe tracking and inspection APIs (`CheckTransferOffer`, `RecordBytesTransferred`, `TryAcquireSession`, `ReleaseSession`, `RecordConnectionAttempt`).

3. **Metered Network Invariant Protection ([`windows/Glide.Core/Remote/MeteredNetworkProtection.cs`](../../../windows/Glide.Core/Remote/MeteredNetworkProtection.cs)):**
   - Implements OS metered network protection invariants (Threat R05) per Specification Section 6.1 & 6.2:
     - `NetworkCostType`: `Unrestricted`, `Metered`, `Unknown`.
     - `MeteredNetworkState`: encapsulates metered flag and connection cost taxonomy.
     - `IMeteredNetworkDetector`: clean abstraction bridging to native OS APIs (Android `NET_CAPABILITY_NOT_METERED`, Windows `NetworkCostType`, Apple `nw_path_is_expensive`, Linux `Metered`).
     - `MeteredTransferPrompt`: constructs the standardized user warning dialog:
       - Displays item name, formatted byte size (e.g., 340 MB), carrier fee warnings, and explicit user action buttons (`[Cancel Transfer]` vs `[Proceed on Cellular]`).
     - `MeteredTransferPolicy`: deterministic policy engine preventing silent cellular data consumption.
