1. **Specified** — design/spec/ADR exists.
2. **Implemented** — relevant source exists.
3. **Automated-tested** — executable unit/integration/fixture evidence exists.
4. **Physically/interoperability verified** — actual production path demonstrated in the named environments.
5. **Released** — exact reviewed artifact/commit has external publication/distribution evidence.
6. **Unverified** — stronger claim is not supported by current HARD evidence.
