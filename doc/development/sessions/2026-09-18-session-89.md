## 1. Summary of Changes

Delivered **Milestone M28**, completing **Phase A2** of the Apple Platforms (iOS, iPadOS & macOS) architecture ([`APPLE_PLATFORMS_SPECIFICATION.md`](../../future/APPLE_PLATFORMS_SPECIFICATION.md) Sections 3 & 4):

1. **SubjectPublicKeyInfo (SPKI) Fingerprint Validator ([`SpkiPinningValidator.swift`](../../../apple/GlideCoreKit/Sources/GlideCoreKit/Transport/SpkiPinningValidator.swift)):**
   - Pure Swift implementation using `CryptoKit.SHA256`.
   - Extracts raw public key bytes and computes 64-character lowercase hex SHA-256 fingerprint.
   - Enforces constant-time verification (`constantTimeCompare`) preventing timing side-channel attacks during TLS 1.3 certificate validation (`sec_protocol_options_set_verify_block`).
   - Strictly rejects invalid hash lengths and non-hex characters.

2. **Bonjour mDNS Discovery Engine & Peer Model ([`BonjourService.swift`](../../../apple/GlideCoreKit/Sources/GlideCoreKit/Transport/BonjourService.swift)):**
   - Configures canonical Bonjour service type `_glide._tcp` in the `local.` domain.
   - Implements standard TXT record schema: `v=1`, `name=<Host>`, `spki=<Hex>`, `presence=<Token>`.
   - Encapsulates `BonjourPeer` with strict schema validation (rejecting missing keys, protocol mismatches, or malformed SPKI fingerprints).

3. **Network Transport Configuration ([`NetworkTransportConfig.swift`](../../../apple/GlideCoreKit/Sources/GlideCoreKit/Transport/NetworkTransportConfig.swift)):**
   - Defines strict network parameters: default port `42424`, TLS 1.3 exclusivity (`TLSv1.3`), TCP keepalive (idle = 10s), and Wi-Fi Direct / link-local peer-to-peer enablement (`includePeerToPeer = true`).
   - Enforces wire ceilings: 16 KiB control ceiling and 64 KiB data chunk ceiling.

4. **Comprehensive Swift Unit Test Suites ([`GlideCoreKitTests`](../../../apple/GlideCoreKit/Tests/GlideCoreKitTests/)):**
   - [`SpkiPinningValidatorTests.swift`](../../../apple/GlideCoreKit/Tests/GlideCoreKitTests/SpkiPinningValidatorTests.swift): verifies SPKI SHA-256 calculation, constant-time equality, case-insensitivity, length validation, and malformed hex rejection.
   - [`BonjourServiceTests.swift`](../../../apple/GlideCoreKit/Tests/GlideCoreKitTests/BonjourServiceTests.swift): verifies TXT record construction, dictionary parsing into `BonjourPeer`, missing key handling, and SPKI length bounds.
   - [`NetworkTransportConfigTests.swift`](../../../apple/GlideCoreKit/Tests/GlideCoreKitTests/NetworkTransportConfigTests.swift): verifies default port 42424, TLS 1.3 requirement, and wire payload limits.

5. **Automated Apple Platforms Auditor Hardening ([`tools/verify-apple-platforms-spec.ps1`](../../../tools/verify-apple-platforms-spec.ps1)):**
