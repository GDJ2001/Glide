1. **Pure Swift Package Foundation ([`apple/GlideCoreKit/Package.swift`](../../../apple/GlideCoreKit/Package.swift)):**
   - Configured Swift Package Manager manifest targeting macOS 13+, iOS 16+, watchOS 9+, tvOS 16+.
   - Zero third-party dependencies; pure Swift utilizing standard libraries (`Foundation`, `CryptoKit`).

2. **LAN Profile 1 Wire Records & Codec ([`apple/GlideCoreKit/Sources/GlideCoreKit/Models/LanRecord.swift`](../../../apple/GlideCoreKit/Sources/GlideCoreKit/Models/LanRecord.swift)):**
   - Models `LanRecordKind`: `bootstrap` (`0x01`), `bootstrapResult` (`0x02`), `control` (`0x10`), `data` (`0x20`), `streamEnd` (`0x21`).
   - Implements `LanRecordCodec` framing:
     - 5-byte header: 1-byte kind + 4-byte big-endian UInt32 payload length.
     - Enforces payload bounds: 16 KiB control ceiling, 64 KiB data chunk ceiling, and signed-overflow protection.
     - Full round-trip encoding and decoding for bootstrap, control envelopes, UUID-prefixed data chunks, and stream termination.

3. **Short Authentication String (SAS) Calculator ([`apple/GlideCoreKit/Sources/GlideCoreKit/Security/SasCalculator.swift`](../../../apple/GlideCoreKit/Sources/GlideCoreKit/Security/SasCalculator.swift)):**
   - Implements canonical 6-digit SAS extraction: `(val % 900_000) + 100_000` (guaranteed `[100,000 .. 999,999]`).
   - Implements `calculateSas` hashing client public key, server public key, and session nonce via `CryptoKit.SHA256`.
   - Implements `formatSas` rendering `### ###` (e.g. `492 815`).

4. **Pairing Invitation Domain & Codec ([`apple/GlideCoreKit/Sources/GlideCoreKit/Security/InvitationCodec.swift`](../../../apple/GlideCoreKit/Sources/GlideCoreKit/Security/InvitationCodec.swift)):**
   - Encapsulates `LanInvitation` domain model.
   - Formats and parses canonical QR pairing URI: `glide://pair/v1#<unpadded-base64url(UTF-8 JSON)>`.
   - Enforces 2,768 URI character limit, 2,048 JSON byte limit, non-empty endpoints, 64-character hex SPKI hash, and expiration verification.

5. **Darwin / POSIX Path Sanitizer ([`apple/GlideCoreKit/Sources/GlideCoreKit/Storage/DarwinPathSanitizer.swift`](../../../apple/GlideCoreKit/Sources/GlideCoreKit/Storage/DarwinPathSanitizer.swift)):**
   - Neutralizes directory traversal sequences (`..`).
   - Strips colons (`:`), forward slashes (`/`), backslashes (`\`), and control characters.
   - Normalizes Unicode to Canonical Composition (NFC / `precomposedStringWithCanonicalMapping`).
   - Truncates filenames to 255 UTF-8 bytes while preserving file extensions.
   - Implements collision resolution (`photo (1).jpg`).

6. **Comprehensive Swift Unit Test Suites ([`apple/GlideCoreKit/Tests/GlideCoreKitTests/`](../../../apple/GlideCoreKit/Tests/GlideCoreKitTests/)):**

   - `DarwinPathSanitizerTests.swift`: traversal elimination, colon stripping, fallback names, 255-byte truncation, collision resolution.
