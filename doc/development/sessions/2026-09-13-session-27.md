     - `offerDenialAndImmediateRetryFlow_noResourceLeaks`: Validates that receiver offer rejection (`rejectOffer()`) transitions both endpoints cleanly to `SessionPhase.Cancelled` with 0 committed files, and that an immediate subsequent retry session initiates, transfers, and completes successfully without resource leaks or stale state.

2. **Duplicate Naming Resolution (`data`):**
   - Verified via `FilenameSanitizerTest.kt` in `:data`:
     - `resolveUniqueName returns original name if no collision`: Returns `"photo.jpg"`.
     - `resolveUniqueName increments index on collision`: Resolves `"photo.jpg"` against `["photo.jpg", "photo (1).jpg"]` to `"photo (2).jpg"`.
     - `resolveUniqueName handles files without extension`: Resolves `"README"` against `["README", "README (1)"]` to `"README (2)"`.
     - `resolveUniqueName handles Windows reserved names with duplicates`: Resolves `"CON.txt"` against `["_CON.txt"]` to `"_CON (1).txt"`.
