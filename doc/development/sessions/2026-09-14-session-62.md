3. **Release Candidate Automation Tool ([`tools/build-and-verify-rc.ps1`](../../../tools/build-and-verify-rc.ps1)):**
   - Implemented an 8-step automated release assembly and validation pipeline:
     1. Discovers cryptographic tools (`keytool`, `apksigner`, `zipalign`, `aapt2`, `adb`).
     2. Resolves release keystore or generates a dedicated RSA 4096-bit testing upload key inside `app/build/` (excluded by `.gitignore` and security scans).
     3. Compiles minified release AAB and APK via `:app:bundleRelease` and `:app:assembleRelease`.
     4. Validates artifact sizes and ensures R8 deobfuscation mapping file (`mapping.txt`, 49.78 MB) is non-empty.
     5. Verifies APK Signature Schemes (v2, v3, and v4 fs-verity `.idsig`) using `apksigner`.
     6. Verifies 16 KB page alignment for Android 15/17 compliance using `zipalign -c -P 16 -v 4`.
     7. Audits manifest badging (`aapt2 dump badging`) and writes SHA-256 / SHA-512 checksum manifests to `app/build/outputs/release-artifacts/`.
     8. Installs and launches the signed release APK on the attached emulator runtime (`emulator-5554`), verifying zero startup crashes.

4. **Automated Compliance Verification Suite ([`ReleaseCandidateArtifactVerificationTest.kt`](../../../app/src/test/kotlin/dev/glide/app/release/ReleaseCandidateArtifactVerificationTest.kt)):**
   - 6 automated tests validating release R8 minification, resource shrinking, ProGuard rules, manifest security flags (non-debuggable, no high-risk permissions), full signature scheme declarations, and build script credential hygiene.
