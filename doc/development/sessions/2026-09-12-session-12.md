- **Milestone:** M3 — First real device transfer.
- **Scope:**
  - Implement arbitrary binary source reading from Android `content://` URIs without broad storage permissions (`READ_EXTERNAL_STORAGE` / `MANAGE_EXTERNAL_STORAGE`).

  - Implement bounded byte counter enforcing exact match with offered/metadata size: immediate failure on early EOF or extra byte.
  - Implement `SourceAccess` port implementation in `:data` (`AndroidSourceAccess`) backed by a testable `ContentResolverWrapper`.
  - Add single-file picker bridge in `:app` (`SelectionScreen`, `SelectionUiState`) using `ActivityResultContracts.OpenDocument()`.
  - Wire `GlideRoute.Selection` into `GlideAppNavDisplay` and `HomeScreen`.
  - Write test suite covering the 6 mandatory scenarios: empty file (0B), 10MB streaming, revoked/deleted source, early EOF, extra byte, and cancellation.

## 4. Threat Model & Security Review
- **T05 (Malformed / huge metadata):** Enforced `MAX_FILENAME_CODE_POINTS` (255), `MAX_FILENAME_UTF8_BYTES` (1024), and `MAX_MIME_LENGTH` (127); files $> 64$ GiB rejected immediately.
- **T06 (Path traversal / Unicode / filename attacks):** `FilenameSanitizer` normalizes to NFC, strips path separators (`/`, `\`), null characters, traversal segments (`..`), control characters, and bidi override markers; raw display names never resolve to filesystem paths.
- **T07 (Disk exhaustion / oversized stream):** Bounded byte counter strictly limits reads to `sizeBytes`; extra bytes immediately abort the stream.
- **T08 (Spam / DoS):** Bounded 64 KiB buffer ensures memory footprint remains $< 256$ KiB per pipeline.
- **T10 (Logs leakage):** No file content or unredacted URIs are logged.
- **T11 (Temporary / backup leakage):** Streams directly from granted content URI without creating temporary disk copies.
- **T12 (Malicious share intents / exported components):** Only granted `content://` URIs from `ActivityResultContracts.OpenDocument` are accepted.
- **T15 (Source URI abuse / provider hang):** Resolves metadata and streams off-main on `Dispatchers.IO`; catches `SecurityException` / `FileNotFoundException`; guarantees descriptor and stream closure in `finally` blocks upon cancellation. Zero broad storage permissions requested.
- **T17 (Consent race / process death / false success):** Premature EOF or size discrepancy immediately fails without false success.
