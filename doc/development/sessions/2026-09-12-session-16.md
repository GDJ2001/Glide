## 4. Threat Model & Security Review
- **T06 / T08 (Path Traversal & Insecure File Sharing):** Received files are quarantined in `files/received/` with UUID-based filenames. Third-party viewer applications access content solely through `FileProvider` URIs with sanitized display names, never exposing underlying filesystem layout or untrusted filenames.
- **T12 (Broad FileProvider Exposure):** `file_paths.xml` strictly specifies `<files-path name="received" path="received" />`. No root paths (`<root-path>`), external storage paths, or app private directories (`databases/`, `shared_prefs/`, `noBackupFilesDir/receiving`) are exposed.
- **T17 (Premature / Unverified File Opening):** Files can only be opened when `TransferUiState.Completed` is reached with a non-null `committedFileKey` for a receiver. Corrupted, interrupted, or cancelled files are quarantined or discarded and cannot be opened.
- **T18 (Missing Viewer App Handling):** `FileOpener` catches `ActivityNotFoundException` and returns `NoViewerApp`, displaying user-friendly feedback without crashing the application.
